# ADR 0006 — Protocole de lecture explicite

Date : 2026-10-07.

La campagne v4 a rejeté deux recherches Select-String en lecture seule.
Le protocole v4 du harnais explicite les formes Get-Content et Select-Object
acceptées pour les références. Le contrôleur conserve sa liste stricte ;
les preuves et les deux statuts historiques sont conservés.

Le nouveau candidat intègre DCP 0.1.3 et son abstention lorsque la récupération
officielle échoue. Neuf nouvelles réponses et un smoke installé sont requis.
Aucun résultat précédent ne qualifie ces nouveaux octets.
