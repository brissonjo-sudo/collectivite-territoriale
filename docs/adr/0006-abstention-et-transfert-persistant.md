# 0006 — Abstention et transfert persistants

Date : 7 octobre 2026. Statut : candidat dev.5 non mesuré.

R7 de dev.4 conserve six réponses et six juges frais. OAuth indisponible explique
l'absence de primaire dans trois nominaux, mais pas les annonces avant STOP,
le transfert RH incomplet, les explications de droit sous réserve ni l'absence
d'activation DSI dans le cas technique.

Les contrats locaux distinguent désormais deux voies : analyse avec un primaire
pertinent effectivement reçu, ou faits fournis, inconnues, mesures conservatoires
et questions sans explication juridique de mémoire. Le transfert RH reste actif
jusqu'à la conclusion. La description DSI réclame l'activation réelle même pour
le cadrage technique simple. Le STOP conservatoire précède toute annonce et ne
vaut pas réponse de fond.

Les six pins, les onze opérations de surcharge, les scénarios, les exigences
atomiques, le barème et le harnais restent inchangés. Les références locales
historiques restent présentes et peuvent encore influencer la réponse ; le
contrat les soumet à preuve et ne les transforme pas en consultation actuelle.
Les descriptions restent des instructions, sans garantie d'exécution.

Le lanceur s'arrête sur un MCP non connecté. R7 reste attachée à ses octets ;
dev.5 doit recevoir un nouveau gel, de nouvelles réponses et de nouveaux juges.
Les validations humaines et le smoke Codex restent nécessaires.
