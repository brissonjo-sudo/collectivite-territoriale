# Politique de sécurité

## Versions maintenues

Seule la dernière version publiée reçoit des correctifs de sécurité. Le
[registre des versions](docs/publication.md) indique laquelle : aujourd'hui,
la 1.5.0 (étiquette `v1.5.0`). Les versions antérieures ne sont pas corrigées ;
mettre à jour le plugin depuis la marketplace.

## Signaler une vulnérabilité

Ne publiez aucun détail exploitable, secret ou donnée personnelle dans une
issue publique.

1. Si l'onglet **Security** du dépôt propose **Report a vulnerability**,
   utilisez ce formulaire privé.
2. Sinon, ouvrez une
   [issue](https://github.com/brissonjo-sudo/collectivite-territoriale/issues)
   intitulée « Demande de canal privé (sécurité) », sans aucun détail : le
   mainteneur vous proposera un échange privé.

Indiquez la version du plugin, l'outil utilisé (Claude Code ou Codex) et, une
fois le canal privé ouvert, les étapes de reproduction.

## Périmètre

Ce dépôt couvre le plugin : skills, surcouches, manifestes, catalogues et
outillage de mesure. Les failles du serveur juridique MCP (accès Légifrance et
Judilibre) se signalent sur le dépôt
[`brissonjo-sudo/droit-francais-skill`](https://github.com/brissonjo-sudo/droit-francais-skill).
Les données traitées sont décrites dans la
[politique de confidentialité](PRIVACY.md).

Ce projet est maintenu par une seule personne, sans délai de réponse garanti.
