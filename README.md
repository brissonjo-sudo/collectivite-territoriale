# collectivite-territoriale

> **Dépôt créé, en attente des phases préalables avant remplissage.** Ce
> dépôt deviendra un plugin Claude Code regroupant les skills métier de la
> fonction publique territoriale (`dpm-fpt`, `drh-fpt`, `dpo-ct`, sous
> réserve `DirFi-fpt`) avec un serveur MCP Légifrance/Judilibre câblé.
>
> Avant remplissage : inventaire de `DirFi-fpt` et correctif `dpm-fpt`
> v1.0.5 (pointeurs inter-dépôts et fond réservé), pour ne pas recopier le
> runtime deux fois. Voir le plan d'audit tenu dans le dépôt `Dpm-fpt`.

## Objet visé

Distribuer, en une seule installation, les skills experts d'aide à la
décision pour une collectivité territoriale française, avec le serveur MCP
de vérification juridique (Légifrance/Judilibre) câblé par défaut — ce
qu'un skill seul ne peut pas faire.

## Ce que ce dépôt ne fait pas (encore)

- Aucun contenu de skill n'est versé à ce stade.
- Aucun `.claude-plugin/plugin.json` ni `marketplace.json`.
- Aucun `.mcp.json`.

Ces éléments arrivent une fois les préalables ci-dessus clos, avec un
`upstream.json` figeant la source et la version de chaque skill embarqué.
